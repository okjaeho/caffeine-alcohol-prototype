잔잔 개인정보 처리방침

시행일 2026년 11월 5일

잔잔은 대학 디자인씽킹 수업에서 만든 시험용 서비스(프로토타입)예요. 카페인과 술을 기록하고, 내 몸에 맞는 하루 권장량을 알려 줘요. 의료 기기가 아니고, 광고나 판매에 개인정보를 쓰지 않아요.

1. 어떤 정보를 받나요

언제항목
카카오로 로그인카카오 회원번호, 닉네임, 프로필 사진, 카카오계정 이메일(동의한 경우)
Google로 로그인Google 계정 ID, 이름, 이메일, 프로필 사진
이메일로 가입이메일, 비밀번호(암호화해서 저장하고 누구도 원래 비밀번호를 볼 수 없어요)
처음 설정에서 직접 입력키, 몸무게, 태어난 해, 성별, 임신·수유 여부, 카페인 민감도, 평소 증상, 흡연, 복용 중인 약, 취침 시각, 얼굴 빨개짐, 간 질환·통풍·혈압·혈당 해당 여부, 음주 빈도와 양. 건너뛴 질문은 받지 않아요.
앱을 쓰면서마신 음료·술 기록(이름, 양, 시각, 붙인 사진), 다음 날 몸 상태 답변, 즐겨찾기, 직접 만든 음료·술, 단위·알림 설정

몸 상태와 질환 관련 답변은 건강에 관한 정보라서, 권장량을 계산하는 데만 쓰고 다른 곳에 쓰지 않아요. 답하고 싶지 않으면 건너뛸 수 있어요.

2. 왜 쓰나요

  • 로그인한 사람이 본인인지 확인하고, 계정을 구분해요.
  • 내 몸 정보와 다음 날 답변으로 하루 카페인·알코올 권장량을 계산해요.
  • 기록을 계정에 보관해서 폰을 바꾸거나 다른 기기에서도 이어서 볼 수 있게 해요.
  • 계정 화면에 닉네임이나 이메일을 보여 줘요.

3. 어디에, 얼마나 보관하나요

  • 로그인하지 않으면 모든 정보는 쓰는 기기의 브라우저에만 저장돼요.
  • 로그인하면 Supabase(데이터베이스·로그인 서비스, 서울 지역 서버)에 저장돼요. 데이터베이스는 로그인한 본인만 자기 기록을 읽고 쓸 수 있게 막혀 있어요.
  • '내 기준 → 모든 데이터 지우기'를 누르면 기기와 계정에 보관된 기록이 바로 지워져요. 계정 자체를 없애고 싶으면 아래 문의처로 알려 주세요. 확인 후 지체 없이 지워요.
  • 수업 프로젝트가 끝나 서비스를 닫을 때는 모든 정보를 지워요.

4. 다른 곳에 주나요

다른 회사나 사람에게 팔거나 주지 않아요. 서비스를 돌리기 위해 아래 회사의 시스템을 써요.

회사하는 일
Supabase Inc.기록 저장, 로그인 처리, 권장량 계산 서버
Kakao Corp., Google LLC카카오·Google 로그인 (해당 로그인을 고른 경우)
GitHub, Cloudflare앱 화면 파일 제공 (개인정보는 저장하지 않아요)

5. 내가 할 수 있는 것

  • 내 정보 보기·고치기: 앱의 '내 기준 → 정보 다시 입력하기'
  • 기록 지우기: 기록 옆 ✕ 버튼, 또는 '모든 데이터 지우기'
  • 로그아웃: '내 기준 → 로그아웃'. 이 기기에 있던 기록은 지워지고 계정에는 남아요.
